# compress_textures — інструкція

Цей репозиторій містить скрипт `compress_textures.sh` для оптимізації текстур (PNG, JPG).

## Призначення
Скрипт проходить по вказаній папці з текстурами, автоматично орієнтує, обрізає метадані, змінює розмір до `MAX_DIMENSION` та оптимізує формат/якість для PNG і JPEG.

## Передумови
- macOS або Linux
- Встановлений ImageMagick (команда `magick` повинна бути в PATH)

Перевірити ImageMagick:

```bash
magick -version
```

## Резервна копія (backup)
Перед запуском скрипта рекомендовано створити резервну копію ваших текстур. У репозиторії створена папка `textures_backup`, куди скопійовано поточні файли з `textures/`.

Щоб вручну створити/оновити резервну копію:

```bash
rsync -a textures/ textures_backup/
```

Щоб відновити з резервної копії:

```bash
rsync -a textures_backup/ textures/
```

## Використання
За замовчуванням скрипт обробляє папку `textures`.

Запуск з параметрами за замовчуванням:

```bash
./compress_textures.sh
```

Вказати іншу папку:

```bash
./compress_textures.sh path/to/your_textures
```

Налаштування через змінні оточення:

- `MAX_DIMENSION` — максимальна довжина сторони (пікселів). За замовчуванням `4096`.
- `JPEG_QUALITY` — якість для JPEG (0–100). За замовчуванням `85`.

Приклад запуску з меншою роздільністю та вищою компресією:

```bash
MAX_DIMENSION=2048 JPEG_QUALITY=80 ./compress_textures.sh
```

## Що робить скрипт
- Перевіряє наявність папки та `magick`.
- Для JPEG: автоматичне орієнтування, видалення метаданих, зменшення зразків, інтерлейс, збереження з вказаною якістю.
- Для PNG: для псевдокольорових — конвертація в PNG8 з 256 кольорами, для суцільних — PNG24 або PNG32 з оптимальними параметрами стиснення.
- Замінює файл тільки якщо оптимізований файл менший або якщо була потрібна зміна розміру.

## Примітки
- Скрипт змінює файли на місці. Завжди робіть резервну копію перед запуском.
- Якщо потрібно змінити поведінку (наприклад, додати автоматичне бекапування), можна відредагувати `compress_textures.sh`.
